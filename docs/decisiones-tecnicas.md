# Decisiones técnicas

En este documento se resumen las principales decisiones de refactoring. El diagnóstico y las evidencias antes/después se incluyen en los archivos `diagnostico.md` y `pruebas.md`, y en el informe final (sección 6), respectivamente.

| Decisión                            | Archivos involucrados                                              | Justificación                                                                                                                                                                                                | Evidencia        | Estado actual                                                                               |
| ----------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- | ------------------------------------------------------------------------------------------- |
| Extract Method                      | `sistema.ts` (al momento del cambio)                               | Se extrajo la lógica extensa de los métodos `registrar`, `reporte` y los encargados de la búsqueda para separar tareas y facilitar la lectura, siempre manteniendo el comportamiento externo.                | commit `e046e8b` | La lógica vive en `src/servicios/ServicioSolicitudes.ts`.                                   |
| Move Method                         | `FormatoSalida.ts`, `ServicioSolicitudes.ts`                       | Se trasladó `fichaEstudiante` desde `Sistema` a `FormatoSalida`, porque su responsabilidad es representar los datos de un estudiante y no coordinar las operaciones del sistema.                             | commit `cbf6379` | Método en `src/presentacion/FormatoSalida.ts`.                                              |
| Introduce Parameter Object          | `RegistrarSolicitudInput.ts`, `sistema.ts` (al momento del cambio) | Se reemplazó la lista de siete parámetros del registro de solicitudes por `RegistrarSolicitudInput`. Agrupa los datos de entrada y facilita identificar cada valor al realizar la llamada.                   | commit `72a35f4` | DTO en `src/dto/RegistrarSolicitudInput.ts`; uso en `src/servicios/ServicioSolicitudes.ts`. |
| Extracción de la política de plazos | `plazosPorTipo.ts`, `sistema.ts` (al momento del cambio)           | Se reemplazó el condicional de plazos por una tabla de consulta consultada con `obtenerPlazoSegunTipo`. Se eligió tabla porque la variación entre tipos es un valor numérico, descartando el uso de Strategy | commit `883c267` | Política en `src/politicas/plazosPorTipo.ts`.                                               |

## Compatibilidad

Todos estos cambios buscaron preservar los comandos, mensajes y el formato de `datos.json`. La verificación se documenta en `docs/pruebas.md`, en la sección de pruebas del informe y en el checklist de code review.
